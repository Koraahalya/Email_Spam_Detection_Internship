# Email Spam Detection
Internship Project for AICTE OASIS Infobyte  
By: Kora Ahalya, Jansons Institute of Technology

## Project Overview
This project uses machine learning to classify emails as spam or not spam.  
Dataset: Kaggle SMS Spam Collection

## How to Run
- Open the notebook in Google Colab or Jupyter.
- Upload `spam.csv` to the same directory.
- Run each cell from top to bottom.

## Requirements
- pandas, scikit-learn, nltk
